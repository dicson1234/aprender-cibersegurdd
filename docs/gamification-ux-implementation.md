# Gamification UX incremental implementation

This branch preserves the existing course datasets and previous UI work, then adds a UX layer for:

- sequential theory cards with comprehension checks and explanations
- reading-weighted XP and lesson completion celebration
- visible achievement trophies and streak/XP integration
- shared learning path rendered on Inicio and Aprender
- quick spaced-review deck
- guided lab checklists with persisted step progress
- first-entry onboarding placement
- responsive desktop/tablet/mobile styling

No existing `data/modules.json` theory content is removed or shortened.
