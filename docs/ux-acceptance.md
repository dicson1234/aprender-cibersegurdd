# UX acceptance checklist

- Theory remains intact and is rendered sequentially rather than discarded.
- Reading completion gives more XP than comprehension answers.
- Correct and incorrect answers show immediate explanations.
- Desktop and mobile layouts share the same components.
- Learning path uses locked/available/completed/mastered states.
- Lab explanations remain visible; execution steps become persisted checklists.
- Onboarding is skippable.
